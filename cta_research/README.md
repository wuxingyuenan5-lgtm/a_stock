## 学习原则

每节课程固定形成以下输出：

1. 概念与术语；
2. 数学或机制表达；
3. 实证证据及其局限；
4. 对 BTC、XAUUSD 和 A 股的映射；
5. 对未来策略设计的启示；
6. 需要保留验证的问题。

课程不以寻找某个最优指标为目标，而是逐层建立：

```text
市场与数据 → 信号 → 风险预测 → 仓位 → 组合 → 执行 → 归因与治理
```

## 研究边界

第一阶段策略研发最终仍以纯趋势为核心。Carry、期限结构、套利、宏观因子、机器学习、市场状态模型、新闻文本、订单簿和高频方法会在课程中介绍，但仅用于建立完整认知；除非后续另行立项，不进入首版策略核心。
